# JamBeacon Avatar App

The responsive website and installable mobile web app for JamBeacon.

Included working prototype flows:

- Rockstar avatar builder and saved device profile
- Approximate five-mile Beacon map and privacy copy
- Avatar jam chat and collab-room handoff
- Five drum-loop presets and microphone recording
- Road to Rockmania challenge, points, and care package
- Avatar shop using device-local test points

Payment, real accounts, server-side chat, persistent audio storage, ID verification, and production geolocation matching are intentionally not connected in this build.
