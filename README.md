# JamBeacon Avatar App

Responsive JamBeacon website and installable mobile web app.

## Avatar creator and shop

- The playable roster is Ambilicous (keyboard), C Note (bass), Lee Fingerz (guitar), Beast (guitar), and Dirt Bike Joey (guitar).
- Texas Hippie Child remains the host. Big Show and Democrat Pat are managers; Jrod is a coach with no instrument; Hard Rock Harold is a banjo coach and story NPC.
- The builder, shop preview, profile, chat avatar, and saved selection use the same full-body image for each equipped look.
- Beast and Dirt Bike Joey have five complete outfit variants each. Ambilicous, C Note, and Lee Fingerz each have a complete alternate full-body look.
- Selecting a look in the shop previews its actual image. Buying it with points records ownership, equips it immediately, and persists the selection on the device.
- Custom full-body art can be uploaded as PNG, JPG, or WebP up to 1.5 MB. It appears in the live preview and profile and is stored in device-local browser storage.

## Other prototype flows

- Approximate five-mile Beacon map and privacy copy
- Avatar jam chat and collab-room handoff
- Twelve JamBeacon loop arrangements with preview and microphone recording
- Five-chapter magical-guitar Road to Rockmania campaign with interactive puzzles
- Tx Hippie Child / Guitar Gangsta host guidance throughout the experience

## Production connections

The $9.99 unlock checkout remains a handoff placeholder; no payment is taken. Merchant payment links, real accounts, server-side chat, persistent audio storage, ID verification, and production geolocation matching require service connections.

Run locally with `npm install`, then `npm run dev`. Create a production build with `npm run build`.
